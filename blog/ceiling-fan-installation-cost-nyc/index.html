What drives the price

  • Existing box: it must be fan-rated. If it is not, the support change is flagged before booking.
  • Ceiling height: downrod fans in tall rooms need ladder work and balancing.
  • Controls: remote kits, wall controls and light kits are each tested separately.
  • Fan size and weight: large or heavy fans take longer to hang and balance.
  • Location: outdoor and covered-balcony fans have wet-rated parts to check.

What's included

  • Existing box and support review
  • Mounting, wiring to the existing fan connection and balancing
  • Light kit and remote setup
  • Full speed and direction test

What's quoted separately

  • The fan, downrod, remote or wall control
  • A fan-rated brace: the labor is in the mid tier that names it, the brace itself is a part
  • Patching or painting around the canopy

When it's not a handyman job

  • If the existing setup is not suitable, we flag the needed support or Licensed Master Electrician scope before booking — new circuits, new locations and wiring routes are permit-level work in NYC.

Frequently asked questions

Can you install a fan where there is only a light?

When the box is fan-rated and the wiring already serves that location, yes. Otherwise the box or brace change is flagged first.

Do you set up the remote?

Yes — remote kits, wall controls and light kits are set up and tested as part of the install.

My fan wobbles. Is that a repair or a replacement?

Usually a balancing and mount check, quoted from a short video. If the box is the problem, that is flagged before any work.

How long does a fan swap take?

A like-for-like swap on a fan-rated box is typically done in one visit.
