Common Questions

Dryer Installation FAQ

How much does dryer installation cost in NYC?

Standard electric dryer installation often runs $150-$220 when the vent, outlet, cord, access, and model fit. Gas-ready dryer replacement is quoted after shut-off, model, vent, building, and scope review.

Do you install gas dryers?

We handle gas dryer replacement and setup only when the existing shut-off and appliance location are code-ready. If the job requires Licensed Master Plumber scope, DOB filing, gas piping alteration, or correction work, we flag that before scheduling and coordinate the proper licensed-trade next steps.

Do you inspect the dryer vent?

Yes. We check the existing vent run for kinks, loose clamps, crushed flex duct, lint buildup, and visible airflow issues before closing the job.

What should I send for a fast quote?

Send the dryer model number, delivery status, photos of the laundry space, outlet or gas shutoff, existing vent path, cord or connector details, stacking kit if relevant, and any building or COI requirements.

Can you stack a dryer on top of a washer?

Yes, when the washer, dryer, stacking kit, closet clearance, vent path, and building rules are compatible. Send the model numbers before booking.
