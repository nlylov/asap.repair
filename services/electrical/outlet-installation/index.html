Common Questions

Outlet Installation FAQ

How much does outlet installation cost in NYC?

Standard outlet replacement is quoted after photos and scope review. GFCI-style, USB, outdoor, higher-voltage, added circuit, or new-location requests are reviewed before booking.

Do you install GFCI outlets?

We review GFCI-style replacement requests where existing wiring and box condition are suitable. Wet locations, outdoor areas, and circuit changes are scope-checked before booking.

Can you add an outlet where there isn't one?

New outlet locations may require a NYC Licensed Master Electrician and DOB permit. Send photos first so we can confirm whether the request fits replacement scope.

What should I send for a fast quote?

Send a straight-on outlet photo, a wider room photo, the device type you want installed, whether the outlet is loose, warm, cracked, buzzing, not holding plugs, or not working, and any building or COI requirements.

Do you install higher-voltage outlets?

Dryer, oven, AC, EV charger, and other higher-voltage outlet requests are reviewed before booking because they often require Licensed Master Electrician or permit-level scope.
